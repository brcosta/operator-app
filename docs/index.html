Built for the moments between prompts

Agents are useful.
Context is everything.

When several tasks run at once, the hard part is not starting another process. It is knowing what is happening, where it belongs, and what needs you next.

⌁

Supervise without hovering

Persistent task briefs, pane-routed questions, progress events, artifacts, and optional native notifications make the important moments visible.

▧

Review while work runs

See branch health, changed files, rendered plans, and native diffs side by side with the work that produced them.

↺

Keep continuity, skip the surprises

Managed harness identities and interactive shells can restore safely. Arbitrary one-shot commands stay manual.

✦ Made to be read, changed, and shared

Your work stays yours

Local-first by design.

Operator is designed to be useful without becoming another place your work has to pass through.

◎

No hosted control plane

Run the app locally. There is no service to provision and no prompt ingestion pipeline.

◫

Read-only Git insight

Understand a worktree without inviting accidental staging, discarding, committing, or pushing.

⟐

Scoped local integration

The terminal helper authenticates each session independently before routing events or artifacts.

◌

Redacted, bounded state

Project metadata can persist. Terminal contents, prompts, and credential-like values do not.
